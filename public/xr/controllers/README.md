# Quest controller models

These are the standard left/right controller models and input profiles from
`@webxr-input-profiles/assets` version 1.0.20. The local profile list includes
Meta Quest Touch Plus, Touch Plus v2, and Oculus Touch v3. Controller buttons
and triggers animate through Three.js `XRControllerModelFactory`.

Source: https://github.com/immersive-web/webxr-input-profiles

Distribution: https://cdn.jsdelivr.net/npm/@webxr-input-profiles/assets@1.0.20/dist/profiles/
