# Standard WebXR hand meshes

`left.glb` and `right.glb` come from `@webxr-input-profiles/assets` version
1.0.20, `dist/profiles/generic-hand/`, the standard hand assets used by
Three.js `XRHandModelFactory`. They are hosted locally so hand rendering does
not depend on a third-party CDN during a headset session.

Source: https://github.com/immersive-web/webxr-input-profiles

Distribution: https://cdn.jsdelivr.net/npm/@webxr-input-profiles/assets@1.0.20/dist/profiles/generic-hand/
